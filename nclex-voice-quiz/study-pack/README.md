# Study pack

`From Claude - NCLEX study pack/` is a snapshot of the question bank and guides in a form meant for a
study folder on a computer (Word and Markdown versions of every question with rationales, the
NCLEX-RN blueprint summary, the ChatGPT prompt/import guide, and the app specs). The zip is the same
folder for downloading. To copy it onto a computer, clone this repository (branch
`claude/nclex-quiz-android-app-1asuvm`) and copy the folder wherever you keep your notes.
